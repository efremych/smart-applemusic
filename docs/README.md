# Smart Apple Music

Конструктор плейлистов для **Apple Music** в духе [Goofy](https://github.com/Chimildic/goofy) (Spotify), плюс интеграция с Last.fm. Вся логика — в **Google Apps Script**: бесплатные триггеры, никакого сервера.

## Что умеет

- Автоматически продлевать developer token (раз в 30 дней, без участия человека)
- Следить за music user token и присылать письмо-инструкцию, когда тот протухнет
- Обновлять music user token с телефона в одну кнопку — через [страницу авторизации](/smart-applemusic/auth/)
- Скробблить прослушанное в Last.fm и одновременно накапливать **свою полную историю** в Google Sheet (раз в 15 минут)
- Читать Last.fm: любимые треки, история, топы — как источник для сценариев
- Сценарии плейлистов: источники → фильтры → дедупликация → плейлист-снапшот

## Архитектура

Слой «движка» (правится редко) и слой «сценариев» (правится по желанию):

| Файл | Роль |
|---|---|
| `Config` | чтение Script Properties, константы |
| `Api` | HTTP-транспорт Apple Music: заголовки, ретраи 429/500, обработка 401 |
| `AppleMusic` | доменный слой Apple Music: плейлисты, треки, чарты, история |
| `LastFM` | доменный слой Last.fm: подписи, чтение, скробблинг |
| `Auth` | жизненный цикл токенов: автопродление dev token, watchdog, веб-эндпоинт |
| `Scrobbler` | Apple Music → Last.fm + дозапись в History, точка отсечения дублей |
| `History` | накопительная история прослушиваний в Google Sheet |
| `Scenarios` | пользовательские сценарии плейлистов |
| `Test` | ручные проверки из редактора |

## Триггеры

| Функция | Расписание | Что делает |
|---|---|---|
| `refreshDevToken` | раз в 30 дней | генерирует новый developer token, проверяет на API |
| `checkUserToken` | каждый день | если user token мёртв — письмо с инструкцией |
| `scrobbleRecent` | каждые 15 минут | скробблинг в Last.fm + дозапись в History |

## Ограничения Apple Music API

- **Удаления нет**: ни треков из плейлиста, ни плейлистов — только вручную в приложении «Музыка». Отсюда архитектура: дедупликация до добавления, плейлисты-снапшоты.
- Нет аудио-фичей (danceability/energy).
- История прослушиваний — ~30 последних треков, без точных времён.
- Developer token живёт максимум 180 дней; user token — месяцы, обновляется только интерактивно.
- Rate limit → HTTP 429 (обрабатывается ретраями).

## Регион

Все операции — со storefront **`tr`** (турецкий Apple ID). Чужие каталоги читать можно, добавлять из них в библиотеку нельзя.
